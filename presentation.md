## Среда выполнения

- Хост-система: Windows 11
- Виртуализация: Oracle VirtualBox
- Гостевая система: Fedora Linux 41 (Sway)
- Установочный образ: `Fedora-Sway-Live-x86_64-41-1.4.iso`

---

## Первоначальная настройка

Установка группы средств разработки:

```bash
sudo dnf -y group install development-tools
```

Проверка утилит:

```bash
sudo dnf -y install tmux mc
```

`tmux` и `mc` уже были установлены.

---

## Обновление системы

Первоначальная команда `sudo dnf -y update` столкнулась с ошибкой загрузки пакета из репозитория Cisco OpenH264.

Обновление выполнено альтернативно:

```bash
sudo dnf --disablerepo=fedora-cisco-openh264 upgrade
```

Транзакция завершилась успешно. На момент снятия скриншотов было загружено ядро `6.11.4-301.fc41.x86_64`.

## Процессор и виртуализация

Команда: `lscpu`

- Архитектура: `x86_64`
- Модель CPU: Intel Core i7-12650H (12th Gen)
- Виртуальных CPU: 1
- Гипервизор: KVM
- Тип виртуализации: Full

![Скриншот CPU](screenshots/02-cpu-virtualization.png)

## Оперативная память

Команда: `free -h`

- Всего: 3,8 GiB
- Доступно: 3,1 GiB
- Swap: 3,8 GiB
- Использование swap: 0 B

Значения зафиксированы в момент выполнения команды.

## Корневая файловая система
